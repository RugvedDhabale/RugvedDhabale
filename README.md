## About me

I own the architecture for IoT Gateway firmware across Raspberry Pi, ESP32, STM32, and PLC platforms at **Integrated Active Monitoring (IAM)**. That means leading GPIO/UART/I2C/SPI hardware-software integration, implementing MQTT, MODBUS, BACnet, CAN, HTTP, and CoAP across gateway devices, and working with custom OS kernel configurations on Raspberry Pi to tune the platform for gateway workloads rather than running it stock. I manage Linux-based toolchains, work within Docker for deployment, handle debug escalation and root cause analysis when things break in the field, and drive performance benchmarking across latency, memory, and power. I also mentor junior engineers and enforce C and Python coding standards across the team.

Before IAM, I built full-stack web applications and embedded solutions end to end - from design through deployment - at Crbix Solutions.
